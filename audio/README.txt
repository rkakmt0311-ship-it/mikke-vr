BGM の置き場所

ここに次の名前で音楽ファイルを置くと、自動でループ再生されます（mp3 / ogg / m4a / wav に対応）。
ファイルが無いあいだは、合成した環境音だけが流れます。

  bgm_hub.mp3       … 絵本の部屋（タイトル）
  bgm_toyroom.mp3   … おもちゃ部屋
  bgm_sea.mp3       … 海の中（第2弾）
  bgm_mansion.mp3   … 洋館の書斎（第2弾）

※ おもちゃの楽器はペンタトニック（C メジャー：ド・レ・ミ・ソ・ラ）で鳴ります。
  BGM を C メジャー（または A マイナー）で作ると、楽器と自然になじみます。
