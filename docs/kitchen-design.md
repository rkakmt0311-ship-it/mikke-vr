# キッチンステージ 設計メモ

実装は `js/stages/kitchen.js`（部屋）と `js/catalog/kitchenware.js`（小物）。作り方の手順は `docs/new-stage-guide.md`、見本は屋根裏（`docs/attic-design.md`）。

第一から第三の幕まで遊べる。

## 施主の決定（変えない）
- **洋風の田舎の台所。** ただしきれいにしない。古びて汚れていて、屋根裏の1ページ目のように不気味にする。
- **ごちゃごちゃが主役。** 整った部屋にしない。棚・床・天井まで物で埋める。
- **部屋は広く。**

## 方針
- **絵本:** 第二の絵本「だいどころ」。ID は `kitchen`。
- **第一の幕「だれも こない 夕ごはん」:** 屋根裏の1ページ目と同じ西日の色と暗さ。すすけた窓から光が差し、奥は暗いまま。誰もいない食卓に皿が並び、椅子には人形が座っている。
- **第二の幕「おきゃくさまが くる」:** 夜。青紫の空気に、かまどの赤い明かりとやかんの湯気。第一の幕の夕ごはんが食卓に残っている。
- **第三の幕「まよなかの かくれんぼ」:** 月明かり。食卓は空で、お客と人形が隠れている。そろうと朝になる。

## 三幕で一つの話（2026-11-07、Gemini Argonと相談して決定）
| 幕 | 見つけると | そろうと |
|---|---|---|
| 第一 | 物が人形の皿に並ぶ | 灯りが落ち、ろうそくがつき、こちらの椅子が引かれる |
| 第二 | お客が空いた席に座り、こちらを向く | やかんが鳴り、お客が全員こちらの席を見る |
| 第三 | お客と人形が席へ戻る | 朝になり、全員消える。自分の席に朝ごはんが残り、かえるは窓辺で外を見ている |

- **第一の幕のかまどの目は、第二の幕のネズミ。** 人形にしない。第三の幕で「あの子」の居場所がすぐ分かるうえ、食卓にいた人形と矛盾する。
- **第三の幕で隠れている人形は移動しない。** 同じ物陰から、見ていない間に顔の向きだけ変える。移動すると「もう調べた」という消去法が崩れる。
- **第三の幕の手がかり:** 先に席へ戻ったお客が、未発見の仲間の方を向く。
- **暗い幕でも輪郭が見える明るさを保つ。** 暗さは明度ではなく色で出す。
- **終わりはやさしく。** 第一・第二の幕の緊張が、もてなしだったと反転する。

## 見つける楽しさの設計（2026-11-07、Gemini Argonと相談して決定）
### リスト
いつも見える。自動では閉じない。PCはTab、スマホはボタンで自分でたたむ。覚えさせることに面白さはない。

### 何に反応させるか
| 対象 | 照準を合わせたとき | 押したとき |
|---|---|---|
| お題・ひみつ | 反応しない。無いものとして判定する | ミッケ！ |
| 部屋の仕掛け | 2.2m以内なら「さわる」 | 動く |
| 本や目次 | 距離を問わず「さわる」 | 動く |
| それ以外 | 反応しない | 「コツ」と鳴り、照準がふるえる |

- **シグニファイアは「何ができるか」を示す。「答えがどこか」は示さない。** この線を越えると探すゲームが壊れる。
- 開く物は見た目で分かる（冷蔵庫は光がもれ、引き出しとかまどは少し開いている）。開かない物は取っ手をなくすか板で打ちつける。
- 開く物すべてにお題を入れると、なぞって開けるだけで解ける。だから、かまどにはお題を入れず、目がのぞく驚きを置く。

### 「仮説→検証→歓喜」は物探しに当てはまるか
- **隠し場所には当てはまらない。** 「怪しい所を調べれば報われる」という約束は破らない。
- **見つける瞬間には当てはまらない。** 棚の物は、推理より先に急に目に飛び込む。ただし3Dでは「どの辺りへ行くか」の仮説が先に起きる（Argonの指摘）。
- **当てはまるのは、物語と意味の階層。** 物を見つける行為はそのままに、「何のために集めていたのか」を途中で裏切る。

### 夕ごはんの仕掛け（第一の幕）
説明の文字は出さない。
1. 人形の前に空の皿が並ぶ。食卓だけが部屋で唯一、片づいている。
2. 見つけた物は、食卓を見ていない間に皿へ並ぶ。カチャッと音がする。
3. 6つそろうと灯りが落ち、ろうそくに火がつき、空いた椅子がこちらへ引かれる。カチッ、ギィと音がする。
4. そのあと人形は金の卵を指さす。卵を見つけると、こちらの席の皿に載る。

### 人形の指さし
- 25秒見つからないと、見ていない間に、まだ見つかっていない物を首と腕で指す。40秒で一度だけ物音を立てる。
- 説明はしない。ヒントの回数も減らない。

### 採用しなかった案
- 「……あの子は、ずっと 見ていたよ」の字幕：子どもに怖すぎ、次に生かす学習にもならない（Argon）。
- 金の卵を最後に椅子へ出す：クリアするまで見つけられなくなる。リストにない「ひみつ」は、いつでも探せるままにする。
- 操作を止める硬直、点数、やり直し：探す手を止めない。

### 確かめられていないこと
面白いかどうかは、人に遊んでもらうまで分からない。確かめたいのは次の3つ。
- 夕ごはんに、途中で自分で気づくか。
- 指さしに気づくか。ヒントとして当たりすぎないか。
- 最後の椅子は、子どもに怖すぎないか。

## 不気味さの作り方
- しみの浮いた壁、ひびと汚れのタイル、ぼろぼろのカーテン、蜘蛛の巣、さび、枯れかけのハーブ。
- 裸電球がときどき震えて暗くなる。
- 人形は、見ていない間だけ、こちらへ首を向ける（屋根裏のくまと同じ「だるまさんがころんだ」）。
- 魚の骨、骨、ねずみとり、燃えさしのろうそくなどが小物に混ざる。
- 音は屋根裏と同じ低い部屋の空気に、きしみと水のしずく。
- 映り込みの光は屋根裏と同じ写真を使う。

## 屋根裏で見つけた問題を繰り返さない
- お題の周りに同じ色の小物を宙にばらまかない。物は棚や皿や床の上に置く。
- 置き場所は、モデルの実際の向きと形を測ってから決める。
- 屋根裏の配置を変えない。台所の小物は屋根裏の一覧（`TOYS`）に入れない。
