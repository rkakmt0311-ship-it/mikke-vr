# 「3Dだからこそ楽しい」要素の設計（Claudeのゲーム分析 ＋ Gemini 4 Argon と相談）

## 参考にしたゲームと、取り入れる理由
| ゲーム | 何がプレイヤーを楽しませているか | このゲームへの取り入れ方 |
|---|---|---|
| Hidden Folks | ほぼ全ての物が触ると反応する。空間に定位した音が探す手がかりになる。弱点は「見つけた時のご褒美が薄い」「同じチャイムが耳障り」 | 触れる仕掛けを増やす。見つけた音は毎回少しずつ変え、続けて見つけると音が上がっていく |
| The Room VR | 接眼レンズで「隠れた層」が見える。手で開ける触覚 | 手持ちの**ルーペ**：かざすと、ふだん見えない物が見える |
| Layers of Fear / P.T. | 背を向けた瞬間に部屋が変わる。ただし連続すると予測されて効果が薄れる | 見ていない間の変化は、**プレイヤーの行動がきっかけ**の時だけ・1ページに1回まで |
| Vlambeer・Juice it or lose it・IEEE 2022 | ヒットストップ・音の一致・カメラが手応えの三大要素。ホラーは画面揺れより微細な動き | 見つけた瞬間に0.1秒の停止、光り、光の粒がリストへ飛ぶ |
| Tetris Effect | 操作と音・光が同期する | 蓄音機を鳴らすと『星月夜』の渦が部屋に溢れ出す |
| Gorogoa / Superliminal | 絵の中の絵、遠近法 | 幻燈機の中の小さな月世界、北斎のめくり本 |

## 著作権が切れた素材（日本・米国・EUで確認）
- 映画：メリエス『月世界旅行』1902、ムルナウ『ノスフェラトゥ』1922、ヴィーネ『カリガリ博士』1920、リュミエール『列車の到着』1896
- 絵画：ゴッホ『星月夜』、モネ『睡蓮』、スーラ『グランド・ジャット島の日曜日の午後』、北斎『神奈川沖浪裏』
- 注意：日本では個人名義の映画は「監督の死後38年」の条件あり（上の4本は満たしている）。絵画の写真は、平面の作品をそのまま写したものなら新しい著作権は生じない扱いが一般的

## 採用した要素
1. **『ノスフェラトゥ』の爪の影**：真夜中、プレイヤーが高く飛んだ時や、ピアノを何度も弾いた後に、壁を這い上がる長い爪の影。音が先、影は後。振り返ったら消えかけている
2. **『月世界旅行』の幻燈機**：のぞき穴に顔を近づけると、中に小さな月世界（右目にロケットの刺さった月）。お題はその中
3. **『カリガリ博士』の棺**：歪んだ書き割り模様の棺。見つめると軋みながら開き、二重底の中が見える
4. **『星月夜』の渦**：蓄音機を鳴らすと、絵から光の渦が溢れ出し、まだ見つけていないお題の近くに集まって数秒照らす
5. **『列車の到着』の幻影**：おもちゃの列車を走らせると、ほこりでできた巨大な機関車の幻が部屋を横切り（汽笛のドップラー効果）、吊り物が揺れて奥が見える
6. **ルーペ（The Roomの接眼レンズ）**：かざすと、ふだん見えない物が見える。ひみつのアイテムの一部はルーペでしか見えない
7. **見つけた瞬間のご褒美**：0.1秒のヒットストップ → 物が内側から光る → 光の粒がリストへ吸い込まれる → 音が解決する。続けて見つけると音が上がる

## びっくり演出の3つのルール（Argon）
1. 引き際の美学：見た時には、もう終わっている（消えかけている）
2. 音を先に、光は弱く：背後で小さな軋み → 振り向くとランプが1秒だけ暗くなる
3. プレイヤーの行動で起こす：高く飛んだ時に10%、ピアノを3回以上弾いた後の最初の振り返り、など。同じ場所で毎回は起こさない

## 見つけづらくする
- お題を小さく（今までの約3分の2）
- お題の周りに、**同じ色の似た小物**を散らす（カモフラージュ）
- 吊り物が揺れて、隙間から一瞬だけ見える
- 覗き込まないと見えない場所（幻燈機・棺・ラッパの奥）を増やす
- ルーペでしか見えない物
